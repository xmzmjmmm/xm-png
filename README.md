# 图片隐写

**把文件嵌入一张图片里。**

</div>

直接运行即可，输入数字选择功能。

### Python 版

安装依赖：

```bash
pip install numpy pillow
```

```bash
python xm.py
```

### Android 原生版

```bash
./xm-android-arm64
```

## 使用须知

- 本工具用于个人数据隐蔽存储等合法用途，请遵守所在法律法规
- 嵌入后的图片请以 **PNG 无损** 方式传输，二次压缩（如微信聊天压缩）可能破坏数据
- 主密码请务必记牢，密码一旦丢失，数据无法找回
